# APKG互換性

FukushuはAnkiの`.apkg`をブラウザ内で解析し、カードのプレビュー・保存・学習・再取込に対応します。標準カードと静的なカスタムテンプレートを主な対象とし、Ankiの表示・スケジューラー・アドオンを完全に再現するものではありません。

この文書は2026-09-11時点の実装を整理したものです。公開デッキの検証結果は2026-09-05の記録であり、今回の文書作成時に再測定した結果ではありません。

## パッケージとカード

| 項目             | 対応範囲                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------- |
| 旧形式           | `collection.anki2`、`collection.anki21`（SQLite schema 11）                                  |
| 新形式           | `collection.anki21b`／`collection.21b`（schema 18、protobuf、zstd）                          |
| デッキ           | 複数デッキをそれぞれ問題集として保存。`親::子`の名前を保持。変換後にカードがないデッキは除外 |
| 標準ノート型     | Basic、表裏反転、任意の反転、type-in-answer、Cloze                                           |
| カード数         | ノートから推測して再生成せず、パッケージに存在するカードとordinalを変換                      |
| カスタムノート型 | 保存された表裏テンプレート・フィールド・CSSから静的に変換                                    |
| メタデータ       | タグ、GUID、元note/card/notetype ID、ordinal、元テンプレートを保持                           |

未知のパッケージ世代・schemaは拒否します。将来のAnki形式やすべてのAnkiバージョンへの対応を保証しません。

## テンプレート・表示

| 機能             | 動作・制限                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| フィールド・条件 | `{{Field}}`、`{{#Field}}…{{/Field}}`、`{{^Field}}…{{/Field}}`、`{{FrontSide}}`に対応                                                           |
| フィルター       | `text`、`hint`、`type`、`cloze`、`furigana`、`kana`、`kanji`に対応。ヒントは開閉要素として表示                                                 |
| 特殊フィールド   | `Tags`、`Type`、`Deck`、`Subdeck`、`Card`、`CardFlag`に対応。同名のユーザーフィールドが優先                                                    |
| Cloze            | 複数ordinalとヒントを扱い、解答側で対象箇所を表示。穴のラベルはFukushu独自。入れ子など高度なCloze構文の完全互換は保証しない                    |
| 入力回答         | `type`の正答を取り出し、裏面にも表示。`FrontSide`内の入力回答にも対応。Ankiの入力UI・差分表示そのものの再現ではない                            |
| HTML・CSS        | 検査・除去処理を経て表示。標準の一部レイアウトは通常描画、独自テンプレートはsandbox付きiframeで隔離                                            |
| 簡略表示         | 文章中心のカードは取込時にplain／Markdownへの変換候補を選択可能。メディア・隠し要素・複雑な構造は対象外                                        |
| 数式             | `\(…\)`、`\[…\]`、`$$…$$`をKaTeXで表示。AnkiのMathJaxとすべての命令が一致するわけではない                                                      |
| 旧LaTeX          | `[$]…[/$]`、`[$$]…[/$$]`、`[latex]…[/latex]`は同梱の生成済み画像を参照。画像がない単純な数式はKaTeXへフォールバック。任意TeXはコンパイルしない |

未定義フィールド・未対応フィルターはエラー診断になり、保存を止めます。JavaScript、イベント属性、埋め込み要素、外部参照などは除去・制限されるため、スクリプトで生成する解答やレイアウトは再現できません。TTS、アドオン依存機能、Image Occlusionの互換性は保証しません。

## メディア

- 画像：PNG、JPEG、GIF、WebP、静的SVG。
- 音声：MP3、OGG、WAV、M4A。`[sound:ファイル名]`を音声プレーヤーへ変換します。実際の再生可否はブラウザのコーデック対応にも依存します。
- SVGはスクリプト・外部画像・`foreignObject`などを除去して扱います。
- 同梱メディアをハッシュで識別してIndexedDBへ保存し、表示時にBlob URLへ解決します。外部URLの画像・音声は読み込みません。
- 動画・同梱フォントなど、対応拡張子以外のファイルは警告付きで除外します。欠落メディアも警告になり、音声には「音声なし」を表示します。

危険なHTML/CSSや未対応メディアの警告があっても保存可能な場合があります。保存できたことだけで表示の完全性は判断できないため、プレビューと診断を確認してください。

## 学習履歴・再取込・バックアップ

「Ankiの学習履歴を取り込む」を選ぶと、有効なrevlogを時刻順に再生し、FukushuのFSRS状態を再構築します。評価1〜4をAgain／Hard／Good／Easyへ対応付け、type 0〜3を対象とします。評価・種別・日時が対象外のログはスキップし、診断を表示します。

Ankiのdue・interval・easeやスケジューラー設定をそのまま移す方式ではないため、次回復習日時はAnkiと一致するとは限りません。有効な履歴がないカードは新規状態になります。Anki側の保留・埋め込み状態も移植対象ではありません。

再取込では既存ソースを選び、追加・変更・移動・出題停止を確認して更新できます。GUID＋ordinalを基本に照合し、重複時は元note/card IDで区別します。元パッケージから消えたカードは削除せず出題停止にし、履歴を保持します。対応付けが曖昧なカードには別カードの履歴を推測で割り当てません。

履歴取込をオフにした更新では既存のFukushu履歴を保持します。オンにすると対象カードの履歴をAnki履歴で置き換え、Fukushuでの回答履歴がある場合は確認画面を出します。

Fukushuのバックアップにはカード・学習履歴に加え、元APKGとメディアも含めます。復元時はメディアのハッシュ・サイズ・参照を検査します。これはFukushu用バックアップであり、Ankiとの双方向同期やAPKG再出力ではありません。

## 容量上限

| 対象               |     上限 |
| ------------------ | -------: |
| APKGファイル       |   256MiB |
| 累積展開サイズ     |   500MiB |
| SQLiteコレクション |   250MiB |
| メディア1ファイル  |    50MiB |
| zstd window        |    64MiB |
| ZIP内エントリ      | 10,000件 |

MiBは1,048,576バイトです。暗号化ZIP、危険なパス、破損やサイズ・チェックサム不一致も拒否します。上限内でも端末のメモリやブラウザの保存容量によって取込に失敗する場合があります。

## 検証範囲と再確認

公式Anki 25.9から生成したanki21／21bと、Anki由来のschema 11 fixtureを使用しています。標準カード、Cloze、条件付きテンプレート、画像・音声、履歴、更新時の移動・削除などを検査します。生成元と手順は[fixtureの説明](../packages/anki-import/tests/fixtures/README.md)を参照してください。

2026-09-05の[公開APKG互換性レポート](compatibility/apkg-public-corpus.md)では、12パッケージ・6,559カードが修正後の解析・ブラウザ保存検査に合格しています。表裏の照合対象は152サンプルであり、全カードの目視確認や音声の全件聴取は行っていません。レポート内の対象一覧は修正前の問題記録を含み、現在の未対応一覧ではありません。

[検証対象とSHA-256](compatibility/apkg-public-manifest.json)、[機械可読結果](compatibility/apkg-public-results.json)、[Kaishiの性能測定](compatibility/kaishi-performance.md)を別途記録しています。公開コーパスの再取得・照合手順は互換性レポートを参照してください。

通常のAPKGテストはリポジトリのルートから実行できます。

```sh
pnpm --filter @fukushu/anki-import test
pnpm --filter app exec vitest run tests/apkg-real.test.ts
pnpm --filter app exec playwright test e2e/apkg.spec.ts --workers=1
```

実装の入口は[解析ライブラリ](../packages/anki-import/README.md)、[アプリ側変換](../packages/app/src/application/importApkg.ts)、[保存・履歴再構築](../packages/app/src/application/apkgStore.ts)、[バックアップ](../packages/app/src/application/backup.ts)です。
