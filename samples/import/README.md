# Import samples

- `sample.gift`: GIFTの選択、短答、数値、正誤、Matching、Essay。
- `sample-anki.txt`: Ankiヘッダー、Basic各種、Cloze、deck／notetype／tags／GUID列。
- `sample-anki.csv`: comma区切り、引用符、フィールド内改行、HTML。
- `sample-anki.tsv`: tab区切り、複数deck、逆方向、Cloze。
- `sample-anki-media.zip`: `media-cards.tsv`と参照画像・音声を同梱したZIP。

すべてUTF-8です。ZIP以外はそのままインポート画面で選択できます。`media-cards.tsv`はZIPの内容確認用で、メディア付きの確認にはZIPを使用してください。
